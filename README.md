# OpusStudio - Producción Audiovisual con IA & Conectores de API

## Novedades
- **Validación instantánea de APIs:** Botones dedicados para probar la clave de Gemini, ChatGPT y ai33.pro con verificación de estado.
- **Auto-población de voces de ai33.pro:** Al presionar 'Conectar API', el sistema comprueba la clave e inyecta dinámicamente todas las voces disponibles en el menú desplegable.
- **Casilla Experto de YT:** Optimiza el guión para retención y formato viral.
- **Subtítulos Hand Move:** Arrastrables libremente sobre el reproductor.

## Despliegue en Vercel
1. Descomprime y sube los archivos a GitHub.
2. Importa el repositorio en Vercel.
3. Haz clic en **Deploy**.
